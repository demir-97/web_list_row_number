List View Row Number — A “#” Column for Every List, Out of the Box

Odoo's list views don't show a row number. This module adds one — everywhere: main list views, and the embedded one2many / many2many tables inside a form. No configuration, no view XML changes.

✓ Odoo 17.0✓ Odoo 18.0✓ Odoo 19.0

How it works

  1. Install the module.
  2. Open any list view (Contacts, Sales Orders, an order lines table …).
  3. A # column is already there, on the left, numbering every row.

Behavior

  • Numbering follows the page — page 2 of an 80-per-page list starts at 81, it does not restart at 1.
  • Inside a grouped list, numbering restarts at 1 for each group.
  • Purely presentational — no field is added, computed or stored, so it has zero effect on exports, imports, filters or any other module.

Limitation

List/tree views rendered by a fully custom renderer (for example sale order lines' section-and-note renderer) replace the standard list renderer outright, so they are not affected.

Technical

Client-side only: one OWL template extension (t-inherit on web.ListRenderer) plus a small stylesheet. No models, no views, no security rules, no server-side code at all.

Frequently asked questions

Does this add a new field to my models?
No. It's purely presentational — one OWL template extension, nothing stored, computed, exported or imported.
Will the numbers show up in my Excel export?
No, the column is display-only and has no effect on exports, imports or filters.
Does it work on Kanban or Calendar views?
No — only list/tree views, including the embedded one2many/many2many tables that use Odoo's standard list renderer.
